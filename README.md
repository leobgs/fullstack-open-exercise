# Full Stack Open - University of Helsinki

This repository contains my solutions and documentation for the Full Stack Open course. My goal is to master fullstack development by focusing on JavaScript, TypeScript, and Node.js through the lens of First Principles and Computational Thinking.

## Branching Strategy

To keep the project organized and each part isolated, I am using a Git branching strategy. Each part of the course lives in its own branch rather than a separate folder on the main branch.

| Branch Name | Part Topic | Current Status |
| :--- | :--- | :--- |
| main | Navigation and Project Overview | Active |
| part0 | Fundamentals of Web Applications | Completed |
| part1 | Introduction to React | In Progress |
| part2 | Communicating with Server | Upcoming |
| part3 | Programming a Server with NodeJS and Express | Upcoming |
